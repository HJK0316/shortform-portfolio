# Short-form Video Editing Portfolio

개인 영상 편집 포트폴리오의 GitHub Pages 소스입니다.

- **사이트:** https://hjk0316.github.io/shortform-portfolio/
- **담당:** 김혁진
- **분야:** 연예인·K-POP·예능 쇼츠 / 쇼핑·제품 소개 쇼츠
- **구성:** HTML/CSS 기반 단일 페이지, PC·모바일 반응형
- **동영상:** 원본 영상은 YouTube 및 Google Drive 링크로 연결됩니다. 이 저장소에는 원본 영상 파일을 넣지 않습니다.

## 편집 및 배포

루트의 `index.html`을 수정하고 `main` 브랜치에 커밋하면 GitHub Pages가 재배포합니다.

메뉴: GitHub 저장소 → Settings → Pages → **Deploy from a branch / main / (root)**

### 보존 및 운영 원칙

기존 노션 포트폴리오와 다른 GitHub 프로젝트는 별개입니다. 영상의 제목·썸네일·링크를 수정할 때는 현재 영상 ID와 실제 접근 가능 여부를 확인해 주세요. 제작물 목록을 변경할 경우 모바일 레이아웃과 링크 동작을 함께 확인합니다.
