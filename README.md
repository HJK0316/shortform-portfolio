# Short-form Video Editing Portfolio

개인 영상 편집 포트폴리오의 GitHub Pages 소스입니다.

- **사이트:** https://hjk0316.github.io/shortform-portfolio/
- **담당:** 김혁진
- **분야:** 연예인·K-POP·예능 쇼츠 / 쇼핑·제품 소개 쇼츠
- **구성:** HTML/CSS 기반 단일 페이지, PC·모바일 반응형
- **동영상:** 원본 영상은 YouTube 및 Google Drive 링크로 연결됩니다. 이 저장소에는 원본 영상 파일을 넣지 않습니다.

## 편집 및 배포

루트의 `index.html`을 수정하고 `main` 브랜치에 커밋하면 GitHub Pages가 재배포합니다.

메뉴: GitHub 저장소 → Settings → Pages → **Deploy from a branch / main / (root)**

### 보존 및 운영 원칙

기존 노션 포트폴리오와 다른 GitHub 프로젝트는 별개입니다. 영상의 제목·썸네일·링크를 수정할 때는 현재 영상 ID와 실제 접근 가능 여부를 확인해 주세요. 제작물 목록을 변경할 경우 모바일 레이아웃과 링크 동작을 함께 확인합니다.


## 포트폴리오 관리 기준 (2026-11-02)

**이 저장소의 GitHub Pages가 최신·공식 포트폴리오입니다.** 영상 작업물 추가·수정은 `main/index.html`과 공개 웹사이트 https://hjk0316.github.io/shortform-portfolio/ 를 기준으로 진행합니다.

- 과거에 공유한 노션 페이지는 **기존 링크 이용자를 위한 보존본**입니다. 삭제하지 않지만 새 영상을 등록하거나 갱신하지 않습니다.
- 기존 유튜브 새 영상 확인 자동화도 노션 대신 이 저장소의 `index.html`에 등록하도록 변경되었습니다. 자동화가 실제로 정상 등록했는지는 매번 커밋과 공개 Pages 결과로 검증해야 합니다.
- 신규 영상 등록 전 현재 카드·YouTube ID·Google Drive 링크와 중복을 확인하고, 기존 작업물·디자인·반응형 레이아웃을 보존합니다.
- 요청하지 않은 자동 동기화 시스템이나 별도 기능은 추가하지 않습니다.
- 배포 후 실제 페이지 접속, 링크, 썸네일, 모바일 레이아웃을 확인합니다.
